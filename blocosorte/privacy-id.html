Bloco da Sorte – Kebijakan Privasi

English version

Tanggal berlaku: 20 November 2026

Bloco da Sorte ("game") adalah game puzzle blok untuk satu pemain yang dapat dimainkan secara offline.

Informasi yang kami kumpulkan

Kami tidak mengumpulkan, menjual, atau membagikan data pribadi apa pun. Game ini tidak mengumpulkan data pribadi maupun data penggunaan Anda.

Akses internet

Game dapat dimainkan sepenuhnya tanpa koneksi internet. Saat dibuka dengan koneksi internet, game akan terhubung ke server kami hanya untuk memeriksa dan memuat pembaruan konten halaman game. Tidak ada koneksi jaringan lain, dan tidak ada data pribadi yang dikirim. Game tidak meminta izin perangkat lainnya.

Data yang tersimpan di perangkat Anda

Progres, skor terbaik, koin, statistik, dan pengaturan Anda disimpan secara lokal di perangkat agar Anda dapat melanjutkan bermain nanti. Data ini tidak pernah meninggalkan perangkat Anda. Anda dapat menghapusnya kapan saja melalui pengaturan game, dengan menghapus data aplikasi, atau dengan menghapus instalasi game.

Iklan, analitik, dan pihak ketiga

Game ini tidak memiliki iklan, analitik, akun pengguna, pembelian dalam aplikasi, maupun SDK pihak ketiga.

Anak-anak

Game ini tidak ditujukan untuk anak di bawah usia 13 tahun, dan kami tidak dengan sengaja mengumpulkan informasi dari mereka. Karena game tidak mengumpulkan data pribadi dari siapa pun, tidak ada informasi yang perlu dihapus.

Perubahan

Jika kebijakan ini berubah, versi terbaru akan dipublikasikan di halaman ini beserta tanggal berlaku yang baru.
