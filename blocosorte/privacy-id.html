Bloco da Sorte – Kebijakan Privasi

English version

Tanggal berlaku: 21 November 2026

Bloco da Sorte ("game") adalah game puzzle blok untuk satu pemain yang dapat dimainkan secara offline.

Informasi yang kami kumpulkan

Kami tidak menjual informasi pribadi. Game ini sendiri tidak meminta nama, e-mail, atau akun apa pun. Untuk mengetahui asal pemasangan dan cara aplikasi digunakan, game ini memakai layanan analitik AppsFlyer dan Adjust, yang mengumpulkan data perangkat terbatas seperti dijelaskan di bagian “Analitik dan atribusi”.

Akses internet

Game dapat dimainkan sepenuhnya tanpa koneksi internet. Saat dibuka dengan koneksi internet, game akan terhubung ke server kami untuk memeriksa dan memuat pembaruan konten halaman game, dan layanan analitik yang dijelaskan di bawah mengirimkan datanya. Permintaan konten hanya menyertakan hal yang memang selalu ada pada setiap permintaan web (seperti alamat IP, yang mungkin dicatat penyedia hosting di log server standar).

Data yang tersimpan di perangkat Anda

Progres, skor terbaik, koin, statistik, dan pengaturan Anda disimpan secara lokal di perangkat agar Anda dapat melanjutkan bermain nanti. Data ini tidak pernah meninggalkan perangkat Anda. Anda dapat menghapusnya kapan saja melalui pengaturan game, dengan menghapus data aplikasi, atau dengan menghapus instalasi game.

Iklan, analitik, dan pihak ketiga

Game ini tidak menampilkan iklan dan tidak memiliki akun pengguna maupun pembelian dalam aplikasi.

Analitik dan atribusi

Kami menggunakan AppsFlyer (AppsFlyer Ltd.) dan Adjust (Adjust GmbH) untuk mengetahui asal pemasangan dan cara aplikasi digunakan. Layanan ini dapat mengumpulkan ID iklan Google, informasi perangkat dan aplikasi (seperti model perangkat, versi sistem operasi, bahasa, dan versi aplikasi), alamat IP, sumber pemasangan (install referrer), serta aktivitas dalam aplikasi (seperti membuka aplikasi atau masuk ke konten online kami). Kami tidak mengirimkan nama, ID pengguna, jumlah transaksi, atau detail pribadi lainnya kepada mereka. Mereka memproses data ini atas nama kami sesuai kebijakan privasi masing-masing: AppsFlyer dan Adjust. Anda dapat mengatur ulang atau menghapus ID iklan kapan saja di Pengaturan Android › Privasi › Iklan. Kami tidak menggunakan data ini untuk menampilkan iklan kepada Anda.

Anak-anak

Game ini tidak ditujukan untuk anak di bawah usia 13 tahun, dan kami tidak dengan sengaja mengumpulkan informasi pribadi dari mereka. Data analitik yang dijelaskan di atas tidak digunakan untuk mengidentifikasi siapa pun.

Perubahan

Jika kebijakan ini berubah, versi terbaru akan dipublikasikan di halaman ini beserta tanggal berlaku yang baru.
