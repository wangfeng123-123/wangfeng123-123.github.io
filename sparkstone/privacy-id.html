Sparkstone – Kebijakan Privasi

Terakhir diperbarui: 20 November 2026

Kebijakan ini berlaku untuk game Android Sparkstone.

Ringkasan

Sparkstone tidak mengumpulkan, menjual, maupun membagikan data pribadi apa pun. Game ini bisa dimainkan secara offline. Aplikasi terhubung ke server kami untuk memeriksa dan memuat pembaruan konten halaman game; selain itu, aplikasi tidak melakukan koneksi jaringan lain dan tidak meminta izin Android lainnya.

Akses internet

Satu-satunya aktivitas jaringan adalah memeriksa dan memuat pembaruan konten halaman game dari server kami. Permintaan ini tidak mengirim informasi tentang kamu atau perangkatmu di luar yang memang selalu menyertai setiap permintaan web (misalnya alamat IP, yang bisa dicatat penyedia hosting dalam log server standar). Data ini tidak dipakai untuk iklan, analitik, maupun pelacakan.

Data yang tersimpan di perangkatmu

Progres, skor, rekor, dan pengaturanmu hanya disimpan di perangkatmu, di penyimpanan privat aplikasi. Data ini tidak pernah keluar dari perangkatmu. Kamu bisa menghapusnya kapan saja lewat opsi reset di dalam aplikasi, dengan menghapus data aplikasi di pengaturan Android, atau dengan menghapus instalasi game.

Yang tidak dilakukan game ini

  • Tidak ada akun, login, maupun pendaftaran.
  • Tidak ada iklan dan tidak ada ID iklan.
  • Tidak ada analitik, pelaporan crash, atau SDK pihak ketiga lainnya.
  • Tidak ada pembelian dalam aplikasi.
  • Tidak mengakses lokasi, kontak, kamera, mikrofon, foto, atau berkasmu.
  • Tidak ada koneksi jaringan selain memuat pembaruan konten game dari server kami.

Anak-anak

Sparkstone tidak ditujukan untuk anak di bawah 13 tahun. Karena game ini tidak mengumpulkan data pribadi, kami tidak dengan sengaja mengumpulkan informasi pribadi dari siapa pun, termasuk anak-anak.

Perubahan kebijakan ini

Jika versi game di masa mendatang mengubah cara data ditangani, halaman ini akan diperbarui sebelum versi tersebut dirilis, dan tanggal di atas akan berubah.
