Voltrune – Kebijakan Privasi

Terakhir diperbarui: 21 November 2026

Kebijakan ini berlaku untuk game Android Voltrune (paket com.voltrune.game).

Ringkasan

Voltrune tidak menjual data pribadi. Game ini bisa dimainkan secara offline. Aplikasi terhubung ke server kami untuk memeriksa dan memuat pembaruan konten halaman game. Untuk mengetahui asal pemasangan dan cara aplikasi digunakan, game ini memakai layanan analitik AppsFlyer dan Adjust, yang mengumpulkan data perangkat terbatas seperti dijelaskan di bagian “Analitik dan atribusi” di bawah.

Akses internet

Aktivitas jaringan terdiri dari memeriksa dan memuat pembaruan konten halaman game dari server kami, ditambah lalu lintas analitik yang dijelaskan di bawah. Permintaan konten tidak mengirim informasi tentang kamu atau perangkatmu di luar yang memang selalu menyertai setiap permintaan web (seperti alamat IP, yang mungkin dicatat penyedia hosting di log server standar).

Data yang tersimpan di perangkatmu

Progres, skor, rekor, dan pengaturanmu hanya disimpan di perangkatmu, di penyimpanan privat aplikasi. Data ini tidak pernah keluar dari perangkatmu. Kamu bisa menghapusnya kapan saja lewat opsi reset di dalam aplikasi, dengan menghapus data aplikasi di pengaturan Android, atau dengan menghapus instalasi game.

Yang tidak dilakukan game ini

  • Tidak ada akun, login, maupun pendaftaran.
  • Tidak ada iklan yang ditampilkan di dalam game.
  • Tidak ada pembelian dalam aplikasi.
  • Tidak mengakses lokasi, kontak, kamera, mikrofon, foto, atau berkasmu.

Analitik dan atribusi

Kami menggunakan AppsFlyer (AppsFlyer Ltd.) dan Adjust (Adjust GmbH) untuk mengetahui asal pemasangan dan cara aplikasi digunakan. Layanan ini dapat mengumpulkan ID iklan Google, informasi perangkat dan aplikasi (seperti model perangkat, versi sistem operasi, bahasa, dan versi aplikasi), alamat IP, sumber pemasangan (install referrer), serta aktivitas dalam aplikasi (seperti membuka aplikasi atau masuk ke konten online kami). Kami tidak mengirimkan nama, ID pengguna, jumlah transaksi, atau detail pribadi lainnya kepada mereka. Mereka memproses data ini atas nama kami sesuai kebijakan privasi masing-masing: AppsFlyer dan Adjust. Anda dapat mengatur ulang atau menghapus ID iklan kapan saja di Pengaturan Android › Privasi › Iklan. Kami tidak menggunakan data ini untuk menampilkan iklan kepada Anda.

Anak-anak

Voltrune tidak ditujukan untuk anak di bawah 13 tahun, dan kami tidak dengan sengaja mengumpulkan informasi pribadi dari anak-anak. Data analitik yang dijelaskan di atas tidak digunakan untuk mengidentifikasi siapa pun.

Perubahan kebijakan ini

Jika versi game di masa mendatang mengubah cara data ditangani, halaman ini akan diperbarui sebelum versi tersebut dirilis, dan tanggal di atas akan berubah.
